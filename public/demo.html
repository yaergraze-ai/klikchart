klikchart.
SELAMAT DATANG DI DEMO

Jelajahi Klikchart dari setiap sisi.

Pilih peran untuk mencoba alur belanja, pengelolaan toko, dan administrasi.

Ini simulasi lokal dengan data contoh. Tidak ada uang, OTP, atau pengiriman nyata. Data tersimpan selama server demo berjalan dan kembali ke awal saat dimulai ulang.

Pembeli

Temukan produk, simpan favorit, kelola alamat, dan buat pesanan COD.

Coba sebagai pembeli

Penjual

Tambah produk, unggah foto, kelola stok, dan proses pesanan masuk.

Coba sebagai penjual

Owner

Kelola kategori, moderasi produk, tinjau penjual, dan atur marketplace.

Coba sebagai owner

Pengunjung

Jelajahi etalase, pencarian, kategori, dan detail produk tanpa akun.

Jelajahi sebagai tamu

Untuk memakai akun sungguhan, konfigurasi .env dan database Supabase, lalu jalankan npm start. Petunjuk lengkap ada di README.md.
